## 三、趋势信号分析

**1. "Agent Skills / Harness"层全面爆发。** 今日热榜近半数项目（superpowers、Claude-BugHunter、stitch-skills、ECC、last30days-skill）都是围绕编码 Agent 的技能包、性能优化框架或方法论。随着 Anthropic 推动Agent Skills 成为开放标准，社区正从“用什么 Agent”转向“给 Agent 装什么”，skills 生态正在复制当年浏览器插件/App Store 的卡位逻辑。

**2. 人机协作与治理工具首次成批登榜。** plannotator（规划批注工作台）、Tencent/LoopForge（人工审批门）的出现，表明社区关注点从 Agent 能力转向**可控性**——Agent 交付需要审批、审查、反馈闭环。

**3. 上下文/记忆进入“后向量”阶段。** OpenViking、PageIndex、graphify、cognee 均主打“向量库之外”的方案（知识图谱、推理式检索、自进化记忆），与 headroom 这类上下文压缩工具呼应，共同指向**上下文工程**这一新赛道。

**4. 大厂密集卡位。** 阿里（open-code-review、zvec）、腾讯（LoopForge）、字节（OpenViking）、Google（paper-orchestra、stitch-skills）同日上榜，AI 编码与 Agent 基础设施已成为大厂开源竞争主战场，与近期 Claude Code/Codex 生态扩张及 gpt-oss、Qwen 等开源模型的普及直接相关。
